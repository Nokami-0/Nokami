KUCHIYOSE ENGINE — v1.6.0 (Foundry 12–13)
1. Back up your world and existing system.
2. Install the system folder into Data/systems.
3. As GM, select a summoner token, open its sheet, and set Kuchiyose Power Level.
4. Click Summon Creature. Choose a species, power level used, NC, count and power type.
5. The GM confirms chakra spending and the token is created next to the summoner.
6. Select the summoned token to use its separate actor sheet and edit stats.

Rules implemented: chakra = 2 x used level; NC cap = 2 x used level (minus 2 for two summons); 1 use/scene (2 for restricted Hijutsu); dogs can be summoned as eight 1-Vitality helpers; slugs limited to one; a one-species blood contract; below NC4 no damaging attacks; summoned token disappears at zero Vitality. Species list includes all profiles from the bundled Kuchiyose catalog, plus Custom Summon. Creature skill and aptitude choices and natural attacks are pre-populated where documented.

IMPORTANT LIMITATIONS: The supplied books do not give a single fixed stat allocation for every NC/species. The GM must allocate NC4+ attributes, calculate Vitality and Chakra from the character creation tables, and choose purchased aptitudes. Attack items are reference entries, not automated hit/damage rolls. Chakra cost is deducted on summon, but standard-action tracking, Command Partner damage splitting, scene transitions, mount placement, ability prerequisites, free effects, and individual creature chakra costs are not automated. The engine requires a GM; no live Foundry test was performed.
