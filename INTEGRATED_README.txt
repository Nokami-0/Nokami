Shinobi no Sho Revamp 1.5.0 — Unified Catalog & Token Edition

INSTALLATION: Copy ONLY the shinobi-no-sho-revamp folder to Foundry Data/systems/. Select it as your game system. No other module is required to import the included catalogs.

IMPORT: GM -> Game Settings -> Configure Settings -> System Settings -> Unified Catalog & Token Importer -> Open Importer -> Import All Catalogs.

INCLUDED: Existing Revamp system and its native character/item sheets, data from all uploaded catalogs (items/services, weapons, armor, poisons, clans, hijutsu and summon creatures), 27 original summon token assets with the user-provided Kyodaigumo icon, and 12 custom vector item icons. Imported Actors have both portrait and prototype token images. Imported Items have matching images.

IMPORTANT: This is a system-level CATALOG INTEGRATION, not a port of every independent module's automation. Original modules remain in the supplied archive for reference, and their specialized scripts are not automatically enabled by the integrated system. Summon actors are source profiles, not automatically fully calculated stat blocks. A GM must review imported data and mechanics.

The original author credit remains in system.json. All imported catalog data retain source flags. Reimporting does not duplicate records or overwrite edited system data.
