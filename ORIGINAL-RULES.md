# Original STTH rules policy

This edition follows the STTH 1.5.0 rules described in README.md. House-rule mechanics from the customized main branch are not enabled or offered as defaults. Reference: dice p11/p15; Dodge p25; protective equipment p95; vehicle armor p109.

Power 4 / Melee 2 → 2d6 + 2d10. Rank improvements replace dice, not add dice. Higher skill than attribute follows the same larger/smaller rule. Positive overflow Advantage is resolved as additional effective ranks using the existing book check machinery.

No armor DR, Power Block, Speed Parry, Parry reward, Parry penalty, automatically assigned universal magazines, or automatic community boss transformation. Imported documents must be reviewed for custom descriptions and modifiers; they are not automatically converted into original-book content.

The original system ID prevents existing customized worlds from being silently altered. The default compendiums use an edition-specific namespace.
